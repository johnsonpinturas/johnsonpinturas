# Escopo do Projeto PinturaPro

## Objetivo

Reduzir o preenchimento manual de planilhas e centralizar o acompanhamento dos servicos de pintura.

## Cadastros da primeira versao

### Clientes
- Nome
- Telefone
- Endereco
- Tipo de cliente
- E-mail
- Observacoes

### Servicos
- Cliente
- Telefone
- Endereco
- Tipo de imovel
- Tipo de servico
- Data prevista de inicio
- Data prevista de conclusao
- Valor total da obra
- Status
- Orcamento ou descricao
- Observacoes

## Status
- Aguardando retorno
- Em andamento
- Concluido
- Finalizado

## Evolucoes futuras
- Login e perfis de acesso
- Banco de dados compartilhado
- Controle de pagamentos
- Geracao de orcamento em PDF
- Anexos e fotos antes/depois
- Historico de alteracoes
- Backup e recuperacao de dados
